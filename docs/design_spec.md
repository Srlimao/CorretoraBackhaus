### Design Breakdown vs. Specifications

#### 1\. Home Page & Catalogue (Top Left)

-   **Repo Structure Integration:** This grid is generated by the Static Site Generator (SSG) scanning the `content/empreendimentos/` folder. Each card represents one sub-folder (e.g., `residencial-alpha/`).

-   **Visual Elements:**
    
    -   **Thumbnails:** The image displayed is the `thumbnail.jpg` found in the corresponding folder.
    -   **Badges:** The status (e.g., "Lançamento") is pulled directly from the `index.md` metadata (Frontmatter).
    -   **Data Points:** Specs like area (m2), bedrooms, and "Price From" are rendered dynamically from the `index.md` schema.

#### 2\. Property Detail Page (Right Side)

-   **Video Hero:** The specified `video.mp4` is implemented as the main background 'Hero' element. It is designed to autoplay on mute, showcasing the lifestyle aspect immediately.
-   **Metadata Integration:** The titles, tagline ("Vista definitiva para o mar"), and full description are pulled from the `index.md` Markdown content.
-   **Image Gallery:** The grid of images (Fachada, Living, etc.) is generated by the SSG scanning the contents of the `gallery/` sub-folder.
-   **Sticky CTA:** The sidebar (on desktop) contains the conversion forms. The "Falar com Corretor no WhatsApp" button will feature the pre-filled message custom to this property.

#### 3\. Mobile Responsiveness (Bottom Left)

-   **Mobile-First Design:** All elements are stacked for portrait viewing. The video hero remains impactful at the top.
-   **Sticky Conversion:** Critically, the green "Contact via WhatsApp" button remains fixed at the bottom of the viewport, ensuring that the primary call-to-action is always accessible, regardless of how far the user scrolls.

This design is optimized for Astro (using Content Collections) or a similar SSG setup, ensuring zero-JS page loads and excellent Core Web Vitals, crucial for real estate SEO.
